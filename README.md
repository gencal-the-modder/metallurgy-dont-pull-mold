# Metallurgy: Don't Pull Mold
This mod makes so that molds don't get pulled out from casting table (from mod Create: Metallurgy) by hoppers, funnels, pipes from other mods, etc.

**ATTENTION!** Mod intended ONLY for use with Create: Metallurgy version 0.0.6 and Create version below 0.6. In Metallurgy version 0.0.7 and above, compatible only with Create 0.6 and above, there already exists functionality for managing if molds get pulled out of casting table or not.
